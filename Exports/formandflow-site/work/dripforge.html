From garment to design system.

Product concept

A local-first design application for T-shirts, jorts, cargo trousers and dresses. The concept connects a garment library, editable canvas, project collections and export tools so designers can develop and organise garment ideas in one workspace.

Workspace flow · concept architecture
01Choose

Select a garment template and front or back view.

02Design

Edit garment components on a Fabric.js canvas.

03Organise

Group designs into collections and moodboards.

04Export

Create PNG, PDF and tech-pack outputs.

Workspace sketch
A workspace sketch (template panel, editable canvas, layers and export panel), not an application screenshot.
Experience scope

Garment template library, front/back views, editable components, design collections, moodboards, tech-pack generation, PNG and PDF export, and local project storage.

Architecture focus

Separate the garment model, canvas editing state and export structure. Use local storage for project continuity and keep navigation consistent between design, collection and output views.

Tools and technology

React, Vite, Zustand, Fabric.js, Tailwind CSS, jsPDF and HTML Canvas.
