# Codex — instructions for this workspace

This is a reusable design workspace (websites, brand identity, social graphics, presentations).

**Before doing any design work here, read `DESIGN_WORKFLOW.md` in this same folder.** It covers folder structure, project conventions, the standard workflow, and the quality checklist (typography, spacing, contrast, accessibility, mobile, brand consistency).

Key points:
- Keep new work inside `D:\my stuff` unless told otherwise.
- Never move, overwrite, or delete existing files without asking first.
- Drafts go in a project's `Drafts\`; only approved, checked work goes in `Final\`.
- Ask before installing software, purchasing anything, connecting accounts, or uploading private files.
- This workspace is also used by **Claude Code**, which does not share chat history with you. Read and update each project's `HANDOFF.md` so decisions, changes, and verification results carry over between sessions and tools.

## Form & Flow business
`Business-Ops\` runs the freelance studio. Keep the two consistent about the studio's claims and terms, and record decisions in `Business-Ops\HANDOFF.md`.
