# Design Brief — Portfolio Demo: Classic Personal Bio Page

Date: 2026-09-19
Requested by: owner (self-initiated — matches a live opportunity in Business-Ops\01-Opportunity-Pipeline.csv, "Classic Personal Bio Website")

## 1. What is this?
A third portfolio/demo piece: a single-page, classic/elegant personal bio site — serif typography, muted resume-style palette, one portrait photo, simple contact links. Fictional persona, not a real client.

## 2. Purpose / goal
Support a real, live Freelancer.com opportunity that asks for exactly this style (serif type, muted palette, single portrait, future-proofed for adding work-experience/portfolio sections later). Budget there is £250-750 GBP with 34 competing bids averaging £346 — worth a serious proposal.

## 3. Audience
End audience (fictional): visitors viewing a personal introduction page. Real audience: the prospect evaluating a bid.

## 4. Must-haves
- [x] Single responsive page: name/title, one portrait placeholder, short intro text, simple contact links
- [x] Clean serif typography (the brief's own words: "clean serif typography, balanced whitespace, muted resume-style colour palette")
- [x] Structured so sections (work experience, portfolio) can be added later without a rebuild
- [x] WCAG AA contrast, fast-loading, cross-device responsive (mobile/tablet/desktop) — matches the brief's stated acceptance criteria

## 5. Must-avoid
- No real name/photo — placeholder portrait via CSS only (no stock photos), fictional persona, clearly labeled as a demo.
- Not the warm-cream-plus-serif-plus-terracotta look already used for other portfolio pieces — needs its own distinct, genuinely muted/resume-toned palette so all three demos read as different projects.
- **Not written in Chinese.** The real brief asks for the client's own bio text in Chinese (个人简介), but that's the client's content to supply, not something to fabricate. This demo stays in English and the proposal is explicit that the layout is what's being demonstrated — real copy comes from the client in whichever language they choose.

## 6. Brand context
New fictional persona for this demo only. Distinct from the other two demos: muted paper/ink/navy palette instead of warm cream or off-white/terracotta.

## 7. References
None placed — built directly from the live brief's stated requirements.

## 8. Format & deliverables
1 static HTML page + stylesheet: `index.html`, `styles.css`.

## 9. Timeline / priority
Built proactively to support a live, currently-open opportunity.

## 10. Open questions
None blocking the build. Owner still needs to decide whether to actually bid (see pipeline CSV).
