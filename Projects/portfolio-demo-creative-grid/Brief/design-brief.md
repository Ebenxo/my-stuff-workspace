# Design Brief — Portfolio Demo: Creative Portfolio Grid Site

Date: 2026-09-17
Requested by: owner (self-initiated — see Business-Ops\00-Business-Plan.md and Business-Ops\01-Opportunity-Pipeline.csv)

## 1. What is this?
A second portfolio/demo piece: a minimal 3-page creative-portfolio site (landing intro, grid gallery of work, reusable project-detail template). Fictional persona, not a real client.

## 2. Purpose / goal
Directly demonstrate fit for two real, currently-live opportunities logged in the pipeline: "Clean Portfolio Site Design" and "3-Page Portfolio HTML Build" — both want a minimal grid-gallery portfolio in plain HTML/CSS, no sliders/masonry, responsive, easy to extend. This piece should let a tailored proposal honestly say "here's a build in exactly this style" without overstating experience.

## 3. Audience
End audience (fictional): visitors browsing a creative professional's work. Real audience: the two prospects above, evaluating a bid.

## 4. Must-haves
- [x] Landing page: short intro line + one clear CTA into the work grid
- [x] Work/gallery page: even grid (no sliders/masonry), responsive down to mobile, short captions per piece
- [x] One reusable project-detail template page (title, meta, description, placeholder imagery)
- [x] Lightweight nav, fast-loading, plain HTML/CSS/vanilla JS only (matches "3-Page Portfolio HTML Build" brief's explicit ask for no frameworks)
- [x] Fully responsive, no horizontal overflow

## 5. Must-avoid
- No real names, real project work, or stock photos (placeholders only, clearly fictional) — same rule as the first demo piece.
- No sliders or masonry layout — both source briefs explicitly ask for a plain, even grid.
- No frameworks/build step.

## 6. Brand context
New fictional persona for this demo only ("Studio Noir" — generic enough to not misrepresent any real business). Distinct palette from the first demo (dental site used green/cream) so the two demos don't look like the same template reskinned.

## 7. References
None placed — built directly from the two live briefs' stated requirements (even grid, minimal nav, fast-loading, mobile-adaptive).

## 8. Format & deliverables
3 static HTML pages + shared stylesheet: `index.html`, `work.html`, `project.html` (+ `styles.css`).

## 9. Timeline / priority
Built proactively — the two matching live opportunities have "6 days left" as of 2026-09-17, so this was prioritized to support a timely (owner-approved) bid.

## 10. Open questions
None blocking the build. Owner still needs to approve whether/how to actually bid on the two live opportunities (see Business-Ops\01-Opportunity-Pipeline.csv).
