# Tools & permissions reminder

Before Claude Code or Codex does any of the following on this project, ask the owner first:
- Installing any software (e.g. Node.js, ImageMagick, Inkscape, GIMP, fonts)
- Purchasing anything (stock photos, fonts, templates, subscriptions)
- Connecting or authenticating any account (Figma, Adobe, Canva, etc.)
- Uploading any private/project files to an external tool or service

Available now, no install needed:
- **Canva Desktop** — social graphics, presentations, templated layouts (export to Final\ as PNG/PDF when done)
- **Plain HTML/CSS/SVG** opened directly in a browser — no build tools required for most web work
- **Windows Paint / Photos** — basic raster viewing/editing

See `DESIGN_WORKFLOW.md` at the workspace root, Section 6, for the full picture.
