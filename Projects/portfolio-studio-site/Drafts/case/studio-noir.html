The brief

Two live job briefs asked for the same thing: a clean portfolio where the work leads, an even grid with no sliders or masonry, and pages the owner can extend later without a developer. Studio Noir is a sample built to that spec for a fictional designer.

What I checked first

Both briefs ruled out sliders and masonry and asked for plain HTML and CSS, so the structure is three static pages: an intro, a work grid, and one reusable project page.

The grid collapses from three columns to two to one at set widths. Every thumbnail shares one aspect ratio so rows stay aligned.

Decisions
  • An even grid, on purpose.Unequal masonry tiles imply the projects are ranked by size. A uniform grid lets the titles and the work do the ranking.
  • One project template, not one page per project.Adding a project means duplicating a file and swapping the content. It is the answer to “easy for me to update later”.
  • One accent colour on a neutral ground.A portfolio’s job is to frame someone else’s work, so the site stays quiet.
  • Gradient blocks instead of stock photos.Stock imagery would add licensing questions and imply work that does not exist.
Left out

Filters, a lightbox and animated transitions. None of them help a visitor decide to get in touch.

What I would measure

For a real portfolio the test is whether a visitor reaches a project page and then the contact link. Load time on a mid-range phone matters more than any effect.

What went wrong or is unfinished

Honest limitation: a portfolio lives or dies on its real imagery, and this sample has none. The structure is finished; the content is a stand-in.
